## Candidates evaluated

Three strong candidates from recent collection activity (2026-07-06 to 2026-07-08):

1. **Versatron Footmouse (1985)** — Defense contractor making Stinger missile actuators built a foot mouse as their only consumer product. Wonderful juxtaposition. But the interaction model (foot-operated cursor keys via keyboard-wedge) is relatively simple — the story is really about the company, not the interface.

2. **Bandai Terebikko (1988)** — Interactive VHS telephone where cartoon characters "call" the child. DTMF-like tones in VHS audio. Parasocial framing is fascinating. But the interaction model (4 colored buttons decoding tones) is simpler than it first appears. The "lost media" angle is poignant but makes image sourcing fragile.

3. **Big Trak (1979)** — **Selected.** Six-wheeled programmable tank with no screen. Interaction model: typed commands → physical execution, with the gap between the two being the entire point. CMU cognitive psychologists (David Klahr's lab) adopted it to study instructionless learning — one of the only consumer toys pressed into formal scientific use. The interaction model (programming without a screen, the gap between abstract command and physical consequence) speaks most directly to the museum's mission.

- Sega SubRoc-3D: Overlaps with existing Vectrex 3D Imager Field Note (`the-spinning-disk-that-painted-3d.md`)
- Xerox LiveBoard, BAT Keyboard, Gibson Light Pen, Sega R360, Armatron, Logitech ScanMan: Good artifacts but weaker standalone narrative arcs
